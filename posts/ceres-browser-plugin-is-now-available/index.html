Ceres Browser plugin is now available

Ceres Browser plugin is now available. You can now bring practical AI assistance into the browser you already use for reading, writing, emails, messages and everyday online work.

You can download Ceres Browser from the Chrome Web Store.

Ceres beyond VS Code

Ceres Browser is designed for the websites and online tools you use every day. It can help you understand a page, summarize information, improve your writing and prepare better responses without constantly copying text into another application.

Ask questions about the page in front of you

Open the Ceres sidebar while viewing a webpage and ask questions about the content in front of you. You can ask Ceres to explain a difficult section, identify the main points or prepare a short summary.

Work with selected text and open tabs

Ceres can use selected text, the current page and open browser tabs as context for your conversation. You remain in control of the information you include.

Speak your prompts with Ceres Pro

Ceres Pro lets you speak your prompts instead of typing them inside the sidebar. Voice input is useful when your question is long or when typing interrupts what you are doing.

Write better everywhere with Ceres Pro

Voice Rewrite can correct spelling and grammar, shorten a message, expand an idea, change an email tone, translate a response or turn spoken thoughts into clearer writing.

Use built-in AI or your preferred provider

On supported computers, Ceres can use AI built into the browser for selected writing actions. You can also connect services such as OpenRouter, OpenAI, Claude, Gemini, Mistral, Mercury, DeepSeek and Kimi.

Install Ceres from the Chrome Web Store

  1. Open the Ceres Browser page in the Chrome Web Store.
  2. Select Add to Chrome.
  3. Confirm the installation.
  4. Open Ceres from the browser toolbar.
