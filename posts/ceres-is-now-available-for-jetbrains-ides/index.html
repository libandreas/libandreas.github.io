Ceres is now available for JetBrains IDEs

Ceres Assistant is now available for JetBrains IDEs. Install it from the JetBrains Marketplace and bring focused AI assistance into your everyday development environment.

AI assistance inside your JetBrains IDE

Ceres adds a dedicated AI sidebar so you can work with project context without switching applications. You choose the relevant file, selected code, error or development context.

Available for JetBrains IDEs

The plugin supports IntelliJ IDEA, Android Studio, PyCharm, PhpStorm, WebStorm, Rider, CLion, GoLand, RubyMine, RustRover, DataGrip, DataSpell and more JetBrains environments.

Read project information with focused tools

Ceres can work with files, selected code, the active editor file, workspace diagnostics, terminal output, repository information, URLs, PDFs and images. These tools gather context without automatically modifying the project.

Use your voice while coding

Voice input is available directly inside the JetBrains sidebar for prompts, bug descriptions and technical questions.

Connect your preferred AI provider

Ceres supports OpenAI, Anthropic, Mistral, Mercury, OpenRouter, DeepSeek, Kimi and compatible APIs, plus local models through Ollama or LM Studio.

Install Ceres from the JetBrains Marketplace

  1. Open IDE settings.
  2. Select Plugins.
  3. Open the Marketplace tab.
  4. Search for Ceres AI Coding Assistant with Voice.
  5. Select Install.
