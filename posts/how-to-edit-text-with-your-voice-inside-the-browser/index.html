How to edit text with your voice inside the browser

Voice commands can be used to edit text directly inside the browser. This tutorial explains how to use the magic wand button to give an instruction and apply the result to the text you are working on.

You can download Ceres from the Chrome Web Store.

How voice editing works

Place the cursor in a text field or select the text you want to change. Press the magic wand button and start speaking. Describe the result you want naturally: correct a sentence, make a paragraph shorter or change its tone.

Editing text in the same field

After the instruction is processed, the edited text is inserted into the same field. The workflow works in emails, messages, online forms, documents and other browser-based editors.

Examples of voice instructions

Voice commands can correct spelling and grammar, rewrite a paragraph, shorten a message, organize rough notes, change the tone or translate text.

Using the feature in the browser

The magic wand is available next to supported text fields. For more information, see the Ceres Browser page.
