Privacy policy

How Ceres handles user data.

Last updated: September 7, 2026

This Privacy Policy explains how the Chrome extension handles user data. More or less the same applies to the other apps.

Overview

Ceres is a browser assistant that helps users read, write, translate, summarize, speak, capture images, and work with selected browser content.

Ceres does not sell user data, does not use user data for advertising, and does not use user content to train our own AI models.

User content is sent outside the browser only when needed for a feature the user chooses to use, such as sending an AI request to the AI provider.

Data Ceres handles

Depending on the features the user chooses to use, Ceres may handle:

  • Prompts, chat messages, drafts, and assistant responses
  • Selected text and selected HTML from web pages
  • Active tab URL, page title, and page content when the user attaches or requests the current page
  • Screenshots, cropped page areas, pasted images, and selected images
  • Files, pasted content, or attachment content selected by the user
  • Microphone audio when the user starts a voice feature
  • Text extracted from images through OCR
  • AI provider settings, API keys, provider endpoints, selected models, language preferences, and extension settings
  • License key and license status when licensing is used
  • Local usage and feature access information

Ceres does not collect full browsing history for tracking, advertising, or profiling.

How Ceres uses data

Ceres uses data only to provide the feature requested by the user.

For example, selected text may be used for rewrite, grammar, summary, translation, explanation, or chat actions. A screenshot or image may be used for canvas editing, OCR, or an AI image request chosen by the user.

Ceres does not use user data for unrelated advertising, selling data, or building unrelated user profiles.

Bring your own provider

You can connect your own AI provider to Ceres and choose your own AI model for all features. AI requests generally do not pass through our servers; they go directly from the app to the AI provider selected in the app settings. The OpenRouter account connection uses the limited callback described below.

Browser page data

Ceres may access page data such as selected text, selected HTML, page URL, page title, visible tab screenshots, or current page content when the user uses a feature that needs that data.

This data is used to provide actions such as chat, rewrite, grammar correction, translation, summarization, explanation, screenshot capture, image editing, or inserting user-approved output back into the page.

Chrome Web Store Policy

Ceres strictly complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Your data is only used to provide the features you interact with.

In accordance with these policies:

  • Encryption in transit: Any data transmitted to external services is sent over secure, encrypted connections (HTTPS).
  • Human access restriction: We do not allow humans to read your data unless we have your explicit consent (e.g., for technical support), it is necessary for security purposes, or it is required to comply with applicable laws.

AI providers

Ceres can send AI requests to the AI provider.

An AI request may include prompts, selected text, page content, chat context, attached files, images, transcription text, model settings, and other content needed to complete the action requested by the user.

Supported provider types may include OpenAI-compatible providers, OpenRouter, Google-compatible providers, Anthropic-compatible providers, custom endpoints, and local providers.

External AI providers process data according to their own terms and privacy policies. Users should review the privacy policy of the provider they choose.

Free AI access

For user convenience, when no provider has been selected in the extension settings, Ceres automatically selects a provider from the available list in the app settings. The user can change this at any time and connect their own provider by entering their own API key.

Availability and usage limits depend on the provider.

Browser built-in AI

Some Ceres features can use the browser's built-in AI APIs, such as writing, translation, summarization, or language features when available.

When a feature uses browser built-in AI, processing is handled locally by the browser environment. The browser may download the AI model files needed for that feature.

When the user chooses a remote AI provider instead, the request is sent to that selected provider.

Voice and microphone

Ceres uses the microphone only when the user starts a voice or dictation feature and grants microphone permission.

Voice input may be handled by browser-provided speech recognition or by an audio-capable AI transcription model selected by the user.

If browser speech recognition is used, speech processing is handled by the browser or platform provider. If an AI transcription model is selected, the audio needed for transcription is sent to the AI provider.

Ceres does not store permanent voice recordings on our server.

OCR

Ceres can extract text from images using OCR.

OCR is processed locally in the browser. Images used only for OCR are not sent to an AI provider or to our server for OCR processing.

If the user separately chooses an AI chat or image feature with an image, that image may be sent to the AI provider.

Screenshots, images, and canvas

Ceres can capture the visible tab, crop selected page areas, accept pasted images, and provide image or canvas editing features.

Images and screenshots may be stored locally in browser storage while the user works with them.

Images or screenshots are sent to an external AI provider only when the user chooses an AI feature that requires sending that image.

File attachments

Ceres allows users to attach or paste files, including images, text files, code files, structured text files, and PDFs.

Attached content may be read locally so it can be added to the user's prompt or chat context.

Attached content is sent to an AI provider only when the user sends an AI request that includes that attachment or its extracted content.

Local folder access

Ceres may ask the user to select which local folder they want to give access to through the browser File System Access API when the user chooses a feature that needs local file access.

Folder access is optional. When the user grants access, Ceres may scan file names, folder structure, file metadata, and selected file contents locally in the browser to help find relevant information or prepare context for the user.

Local folder contents are not automatically sent to an AI provider or to any external service. Files or extracted file content are sent to the AI provider only when the user chooses to include them in a chat, prompt, or AI request.

Ceres may write generated or edited files inside the folder selected by the user when the user uses a feature that saves files locally.

Folder access information, such as the selected folder name and permission state, may be stored locally in browser storage.

Storage and Chrome Sync

Ceres stores settings and working data using browser-provided storage such as Chrome Storage Local, Chrome Storage Sync, and browser local storage.

Stored data may include API keys, provider endpoints, selected models, language settings, custom prompts, chat history, drafts, attached content, images, license state, and extension preferences.

Ceres stores usage and eligibility information in browser storage to manage access to free and premium features. This information is not sent to us or shared with third parties.

Provider credentials, including AI provider API keys, may be stored in Chrome Storage Sync like other synchronized extension settings. If Chrome Sync is unavailable, the extension may use Chrome Storage Local as a fallback. If Chrome Sync is enabled in the user's browser, Chrome may sync those values between the user's Chrome browser installations. Chrome Sync is provided by Chrome, not by us.

Ceres does not operate its own sync server for Chrome extension conversations, prompts, page content, API keys, files, images, or voice recordings.

OpenRouter connection

Ceres can help users connect an OpenRouter account through a browser-based connection flow that starts only when the user selects the connect button.

OpenRouter returns a one-time authorization code to a static callback page on ceres-assistant.com. An isolated script packaged with the Chrome extension reads that callback and passes the code directly to the extension. The callback does not contain prompts, conversations, selected page content, files, images, audio, the user's OpenRouter password, or the resulting OpenRouter API key.

Ceres does not save the one-time authorization code in an application database or file. As with other HTTPS requests, the hosting provider or security infrastructure may process standard request metadata. The extension combines the one-time code with a private PKCE verifier held only in the browser and exchanges it directly with OpenRouter for the user-controlled API key.

When the user connects OpenRouter, Ceres stores the resulting API key as the same .cred provider credential used for manually configured API keys and stores the provider settings needed to use that account. A Ceres website account is not required for this connection.

OpenRouter processes requests according to OpenRouter's own terms and privacy policy.

License verification

If the user enters a license key, Ceres stores the license key and license status in browser storage.

For Gumroad licenses, Ceres may send the license key to Gumroad to verify the license. Gumroad processes that request according to its own terms and privacy policy.

Version and notice checks

Ceres may contact ceres-assistant.com to check version information, update notices, or product messages but not auto update any source code.

These checks are used to show extension-related notices and do not send prompts, selected text, page content, files, images, or voice recordings.

Data sharing

Ceres shares data only when needed for a feature the user chooses to use.

This may include:

  • Sending AI requests to the AI provider
  • Sending audio to the AI provider when the user uses an AI transcription model
  • Sending a license key to Gumroad when the user verifies a Gumroad license
  • Checking ceres-assistant.com for version information or notices

We do not sell user data. We do not share user data with advertisers. We do not use user conversations, prompts, page content, selected text, images, files, or voice data to train our own AI models.

Analytics

Ceres and Project Skia use GoatCounter, a privacy-friendly and cookieless analytics service, only to count how many times the extension is opened.

Chrome Web Store may provide marketplace-level statistics, such as install counts or store dashboard metrics, according to Google's own policies.

Our public website also uses GoatCounter for site traffic analytics.

Data retention

Locally stored extension data remains in the user's browser storage until the user removes it, clears browser storage, changes settings, or uninstalls the extension.

Data sent to an AI provider is handled according to that provider's retention policy.

License verification data sent to Gumroad is handled according to Gumroad's retention policy.

Data deletion

Users can delete locally stored Ceres data by:

  • Removing saved API keys, provider settings, custom prompts, and license keys inside Ceres
  • Clearing Chrome extension storage or browser local storage
  • Turning off Chrome Sync for extension settings if they do not want synced settings
  • Uninstalling the Ceres Chrome extension

For data already sent to an external AI provider or Gumroad, users should contact that provider or use that provider's account tools.

Security

Ceres uses the permission and storage systems provided by Chrome and the user's browser environment.

Users should protect their browser profile, device, API keys, provider accounts, and license keys.

The security and retention practices of external providers depend on the provider.

Children

Ceres is not directed to children.

Users who are not old enough to use browser extensions or AI providers under the laws of their country should not use Ceres without permission from a parent or guardian.

Changes to this policy

We may update this Privacy Policy when Ceres, its features, or provider integrations change.

The updated version will include a new last updated date.

Contact

For privacy questions, contact developer email or contact form.
